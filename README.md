PokeDecs (Technical Assessment Project)
==================

This apps use pokeapi.co API to display list and details of monsters. Login or register is needed to access the monster list.

## Features

* Hilt Dependency Injection
* MVVM
* Retrofit
* Offline Cache using Couchbase
* UI in Compose, infinite list
* Compose Navigation
* Clean Architecture
* Kotlin Coroutines and StateFlow
* Sample Unit Test for PokeDetailViewModel
